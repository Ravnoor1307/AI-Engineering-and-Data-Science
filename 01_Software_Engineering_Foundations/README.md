# Python for AI Engineers

This repository contains topic-wise learning materials, concept notebooks, tasks, and task solutions.

## Learning workflow
1. Learn the concept before creating its notebook.
2. Practise using the topic tasks.
3. Save completed concept notebooks in the topic's Concept_Notebooks/ folder.
4. Add task solutions after attempting the tasks.
5. Update the relevant topic and module README files.
6. Add completed topics to the master notebook.
