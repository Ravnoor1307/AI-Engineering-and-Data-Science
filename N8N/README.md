## How to use the pack

1. Study topics in numerical order.
2. Redraw each Mermaid diagram from memory and explain the data flow.
3. Complete the guided exercises and knowledge checks in each topic.
4. Build the project guides after learning their prerequisite concepts.
5. Inspect node input/output, test failure paths, and document limitations.

## Relationship to the CampusX repository

The first five topics follow the foundational areas in the supplied [CampusX n8n notes repository](https://github.com/campusx-official/n8n-notes): Introduction to n8n, Types of Workflows, Data Flow in n8n, Basics of n8n, and Installing n8n. Topics 6–19 and the project guides are an expanded curriculum for API integration, AI engineering, RAG, security, deployment, and practical portfolio work; they are not additional CampusX repository chapters.

## Important notes

- n8n changes over time. Verify node names, UI labels, installation commands, and feature availability in the current [official documentation](https://docs.n8n.io/).
- n8n is fair-code; review the current license and commercial terms for your intended use.
- A local learning setup is not automatically production-ready. Self-hosting requires security, backups, upgrades, and monitoring.
- AI outputs are probabilistic. Validate model output and require human approval for consequential actions.
- External images are hotlinked and need an internet connection. Their source pages are listed in [ASSET_SOURCES.md](ASSET_SOURCES.md); check reuse permissions before republishing.
