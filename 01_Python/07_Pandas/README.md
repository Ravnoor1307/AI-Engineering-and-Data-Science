# Module 06 - Pandas

Pandas is the working surface of data analysis in Python. Three weeks here, with real datasets, is the difference between fighting the library and thinking in it.

## Contents

| Folder | What you learn |
| --- | --- |
| [`01_Series_and_DataFrame/`](01_Series_and_DataFrame/) | Index, selection, dtypes, memory, sorting |
| [`02_Data_Cleaning/`](02_Data_Cleaning/) | Missing values, duplicates, type coercion, text normalisation |
| [`03_GroupBy_and_Merge/`](03_GroupBy_and_Merge/) | Split-apply-combine, joins, pivot, melt, time series |
| [`Tasks/`](Tasks/) | Five applied tasks with reference solutions |
| [`Interview_Questions/`](Interview_Questions/) | 30 questions plus 10 coding challenges |

## Suggested study order

1. `01_Series_and_DataFrame`
2. `02_Data_Cleaning`
3. `03_GroupBy_and_Merge`
4. `Tasks`
5. `Interview_Questions`

## How to work through a topic folder

1. Read `00_notes.md` end to end.
2. Run `01_concepts.ipynb` cell by cell, changing values to see what breaks.
3. Work `02_examples.ipynb` - these mirror real project tasks.
4. Solve `03_exercises.ipynb` before reading the solution cells.

Datasets to practise on: [Indian Startup Funding](https://www.kaggle.com/datasets/sudalairajkumar/indian-startup-funding), [Titanic](https://www.kaggle.com/c/titanic/data).
