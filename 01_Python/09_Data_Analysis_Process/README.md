# Module 08 - Data Analysis Process

The end-to-end method: framing a question a stakeholder actually needs answered, gathering and assessing data honestly, exploring it systematically, and writing up a conclusion someone can act on. Three case studies apply the whole process.

## Contents

| Folder | What you learn |
| --- | --- |
| [`01_Framing_the_Problem/`](01_Framing_the_Problem/) | Business question to data question, metrics, scope, pre-mortems, sizing |
| [`02_Gathering_and_Assessing_Data/`](02_Gathering_and_Assessing_Data/) | Sources, quality dimensions, tidiness, defect catalogues |
| [`03_Exploratory_Data_Analysis/`](03_Exploratory_Data_Analysis/) | Univariate, bivariate and multivariate analysis with written observations |
| [`Tasks/`](Tasks/) | Five applied tasks with reference solutions |
| [`Case_Studies/`](Case_Studies/) | Titanic, Indian smartphone market, and web scraping |
| [`Interview_Questions/`](Interview_Questions/) | 30 questions plus 10 coding challenges |

## How to work through a topic folder

1. Read `00_notes.md` end to end.
2. Run `01_concepts.ipynb` cell by cell, changing values to see what breaks.
3. Work `02_examples.ipynb` - these mirror real project tasks.
4. Solve `03_exercises.ipynb` before reading the solution cells.

## Case studies

- [`Case_Studies/Titanic/`](Case_Studies/Titanic/) - survival analysis, feature engineering, interpretable baseline, odds ratios.
- [`Case_Studies/Smartphones/`](Case_Studies/Smartphones/) - price drivers, brand positioning, value-for-money ranking.
- [`Case_Studies/Web_Scraping/`](Case_Studies/Web_Scraping/) - building a dataset responsibly, parsing, pagination, validation, provenance.

Each case study has a `data/README.md` with the real dataset link. The notebooks fall back to faithful synthetic stand-ins so they run offline.
