# Module 02 - Python Data Types

Containers and functions. This module decides whether your future code is a tangle of loops or a clean pipeline. Pay special attention to choosing the right container.

## Contents

| Folder | What you learn |
| --- | --- |
| [`01_Lists/`](01_Lists/) | Mutability, slicing, comprehensions, sorting, cost of operations |
| [`02_Tuples_Sets_Dicts/`](02_Tuples_Sets_Dicts/) | Records, membership, keyed lookup, Counter and defaultdict |
| [`03_Functions/`](03_Functions/) | Arguments, scope, closures, recursion, type hints |
| [`Tasks/`](Tasks/) | Five applied tasks with reference solutions |
| [`Interview_Questions/`](Interview_Questions/) | 30 questions plus 10 coding challenges |

## Suggested study order

1. `01_Lists`
2. `02_Tuples_Sets_Dicts`
3. `03_Functions`
4. `Tasks`
5. `Interview_Questions`

## How to work through a topic folder

1. Read `00_notes.md` end to end.
2. Run `01_concepts.ipynb` cell by cell, changing values to see what breaks.
3. Work `02_examples.ipynb` - these mirror real project tasks.
4. Solve `03_exercises.ipynb` before reading the solution cells.
