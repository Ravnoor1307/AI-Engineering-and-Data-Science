# Module 03 - Python Advanced

Where you stop writing scripts and start writing software. OOP, file IO, exceptions, decorators and generators are the vocabulary of every library you use later.

## Contents

| Folder | What you learn |
| --- | --- |
| [`01_OOP/`](01_OOP/) | Classes, properties, inheritance, dunder methods, dataclasses |
| [`02_File_Handling/`](02_File_Handling/) | Context managers, encodings, CSV, JSON, pathlib |
| [`03_Exception_Handling/`](03_Exception_Handling/) | try/except/else/finally, custom errors, chaining |
| [`04_Decorators_Generators/`](04_Decorators_Generators/) | Closures, decorators, yield, itertools pipelines |
| [`Tasks/`](Tasks/) | Five applied tasks with reference solutions |
| [`Interview_Questions/`](Interview_Questions/) | 30 questions plus 10 coding challenges |

## Suggested study order

1. `01_OOP`
2. `02_File_Handling`
3. `03_Exception_Handling`
4. `04_Decorators_Generators`
5. `Tasks`
6. `Interview_Questions`

## How to work through a topic folder

1. Read `00_notes.md` end to end.
2. Run `01_concepts.ipynb` cell by cell, changing values to see what breaks.
3. Work `02_examples.ipynb` - these mirror real project tasks.
4. Solve `03_exercises.ipynb` before reading the solution cells.
