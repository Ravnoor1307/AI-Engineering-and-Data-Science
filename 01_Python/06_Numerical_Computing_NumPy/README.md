# Module 05 - NumPy

NumPy is the foundation of the scientific Python stack. Pandas, scikit-learn, matplotlib and PyTorch all speak ndarray. Two weeks here pays for itself repeatedly.

## Contents

| Folder | What you learn |
| --- | --- |
| [`01_NumPy_Fundamentals/`](01_NumPy_Fundamentals/) | ndarray, dtypes, indexing, views versus copies, reshaping |
| [`02_Advanced_NumPy/`](02_Advanced_NumPy/) | Broadcasting, ufuncs, aggregation, linear algebra, random |
| [`Tasks/`](Tasks/) | Five applied tasks with reference solutions |
| [`Interview_Questions/`](Interview_Questions/) | 30 questions plus 10 coding challenges |

## Suggested study order

1. `01_NumPy_Fundamentals`
2. `02_Advanced_NumPy`
3. `Tasks`
4. `Interview_Questions`

## How to work through a topic folder

1. Read `00_notes.md` end to end.
2. Run `01_concepts.ipynb` cell by cell, changing values to see what breaks.
3. Work `02_examples.ipynb` - these mirror real project tasks.
4. Solve `03_exercises.ipynb` before reading the solution cells.
