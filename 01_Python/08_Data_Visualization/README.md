# Module 07 - Data Visualization

Charts are how analysis becomes a decision. This module covers the matplotlib object model, seaborn's statistical layer, and interactive plotly output, then applies all three in two projects.

## Contents

| Folder | What you learn |
| --- | --- |
| [`01_Matplotlib/`](01_Matplotlib/) | Figure and axes, plot types, styling, subplots, export |
| [`02_Seaborn/`](02_Seaborn/) | Statistical plots, semantic mapping, faceting, themes |
| [`03_Plotly/`](03_Plotly/) | Interactive charts, figure objects, animation, HTML export |
| [`Tasks/`](Tasks/) | Five applied tasks with reference solutions |
| [`Projects/`](Projects/) | Covid dashboard and an interactive sales explorer |
| [`Interview_Questions/`](Interview_Questions/) | 30 questions plus 10 coding challenges |

## Suggested study order

1. `01_Matplotlib`
2. `02_Seaborn`
3. `03_Plotly`
4. `Tasks`
5. `Projects`
6. `Interview_Questions`

## How to work through a topic folder

1. Read `00_notes.md` end to end.
2. Run `01_concepts.ipynb` cell by cell, changing values to see what breaks.
3. Work `02_examples.ipynb` - these mirror real project tasks.
4. Solve `03_exercises.ipynb` before reading the solution cells.

## Projects

- [`Projects/Covid_Dashboard/`](Projects/Covid_Dashboard/) - time series, regional small multiples, growth rates, deployment notes.
- [`Projects/Plotly_Project/`](Projects/Plotly_Project/) - interactive sales explorer with animation and HTML export.
